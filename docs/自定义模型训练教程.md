## 2. 数据集目录结构

当前使用的是 Ultralytics YOLO 标准目录结构：

```text
datasets/my_dataset/
├── annotations/             # AnyLabeling 的可编辑标注文件
├── images/
│   ├── train/               # 20 张训练图片
│   ├── val/                 # 5 张验证图片
│   ├── test/                # 5 张测试图片
│   └── raw/                 # 后续新拍摄、尚未划分的图片
├── labels/
│   ├── train/               # 训练标签
│   ├── val/                 # 验证标签
│   ├── test/                # 测试标签
│   └── raw/                 # 后续新导出、尚未划分的标签
├── classes.txt
├── image_sources.txt
└── labels_preview.jpg
```

图片和标签必须同名，并放在相同的数据划分中：

```text
images/train/nailong_web_001.jpg
labels/train/nailong_web_001.txt
```

`images/raw` 和 `labels/raw` 只是新数据的临时存放目录，YOLO 训练不会读取它们。

## 3. `dataset.yaml` 配置

项目根目录的 `dataset.yaml` 内容如下：

```yaml
path: /home/zros/EmbodyAI/Yolo_test/yolov26/datasets/my_dataset
train: images/train
val: images/val
test: images/test

names:
    0: nailong
```

各字段含义：

- `path`：数据集根目录。
- `train`：训练图片目录。
- `val`：验证图片目录。
- `test`：测试图片目录。
- `names`：类别编号和名称，编号必须从 `0` 开始。

YOLO 会根据图片路径自动寻找对应标签。例如读取 `images/train/a.jpg` 时，会寻找 `labels/train/a.txt`。

## 7. 正式训练

流程跑通后，使用下面的命令训练 100 个周期：

```bash
/home/zros/miniconda3/envs/rl_learning/bin/python train.py \
    --epochs 100 \
    --patience 0 \
    --name nailong_yolo26n_full
```

当前 RTX 3050 Laptop 已验证 `batch=4` 可以运行。如果显存仍然不足，将它改成 `2`；显存有余量时可以尝试 `8`。

当前验证集只有 5 张图片，早停指标波动很大，因此正式训练使用 `--patience 0` 禁用早停。增加数据后可以重新启用早停，例如
`--patience 30`。

`train.py` 常用参数：

| 参数         | 默认值         | 作用                         |
| ------------ | -------------- | ---------------------------- |
| `--model`    | `yolo26n.pt`   | 预训练模型或模型 YAML        |
| `--data`     | `dataset.yaml` | 数据集配置                   |
| `--epochs`   | `100`          | 最大训练周期数               |
| `--imgsz`    | `640`          | 输入图片尺寸                 |
| `--batch`    | `4`            | 每批图片数                   |
| `--device`   | `0`            | GPU 编号，CPU 使用 `cpu`     |
| `--workers`  | `2`            | 数据加载进程数               |
| `--name`     | `yolo26n`      | 实验目录名称                 |
| `--patience` | `0`            | 早停等待周期，`0` 表示不早停 |

主要输出文件：

```text
runs/my_dataset/nailong_yolo26n_full/
├── weights/
│   ├── best.pt
│   └── last.pt
├── results.csv
├── results.png
├── confusion_matrix.png
└── train_batch0.jpg
```

- `best.pt`：验证集效果最好的模型，测试和实际使用优先选择它。
- `last.pt`：最后一个周期的模型，可用于断点续训。

继续中断的训练：

```bash
/home/zros/miniconda3/envs/rl_learning/bin/yolo detect train \
    resume \
    model=runs/my_dataset/nailong_yolo26n_full/weights/last.pt
```

## 11. 使用 AnyLabeling 标注新图片

启动已经安装好的标注环境：

```bash
env -u PYTHONPATH \
    /home/zros/EmbodyAI/Yolo_test/labeling-env/bin/anylabeling \
    /home/zros/EmbodyAI/Yolo_test/yolov26/datasets/my_dataset/images/raw \
    --output /home/zros/EmbodyAI/Yolo_test/yolov26/datasets/my_dataset/annotations \
    --labels /home/zros/EmbodyAI/Yolo_test/yolov26/datasets/my_dataset/classes.txt \
    --validatelabel exact \
    --autosave \
    --nodata
```

标注规则：

1. 使用矩形框完整框住奶龙主体。
2. 标签选择 `nailong`。
3. 一张图中出现多个奶龙时，每个目标分别画框。
4. 不要漏标清晰可见的目标。
5. 导出格式选择 YOLO 目标检测。
6. 将导出的标签保存到 `datasets/my_dataset/labels/raw`。

标注完成后，`images/raw` 中的图片与 `labels/raw` 中的标签必须同名。

新增数据不能全部只放进训练集。应把同名图片和标签一起分配到 `train`、`val` 或 `test`，并保证一对文件始终位于相同划分：

```text
images/val/new_image.jpg
labels/val/new_image.txt
```

建议总体比例保持在：

- 训练集：约 70%～80%。
- 验证集：约 10%～20%。
- 测试集：约 10%～20%。

来自同一段视频的连续帧非常相似，应放在同一个划分中，否则验证结果可能虚高。

## 12. YOLO 标签格式

每个目标在标签文件中占一行：

```text
class_id x_center y_center width height
```

当前只有 `nailong` 类别，因此每一行的类别编号应为 `0`：

```text
0 0.500000 0.480000 0.600000 0.800000
```

后四个数字是相对于图片宽高归一化后的坐标，范围必须在 `0～1`。

## 13. 常见问题

### 找不到 PyTorch

如果出现：

```text
ModuleNotFoundError: No module named 'torch'
```

说明使用了系统 Python。改用：

```text
/home/zros/miniconda3/envs/rl_learning/bin/python
```

### 找不到图片或标签

检查目录和数量：

```bash
find datasets/my_dataset/images/train -maxdepth 1 -type f
find datasets/my_dataset/labels/train -maxdepth 1 -type f
```

图片和标签的文件名必须一致，只有扩展名不同。

### 类别编号超出范围

当前 `dataset.yaml` 只有一个类别，因此合法类别编号只有 `0`。标签中出现 `1` 或更大的编号都会报错。

### CUDA 显存不足

减小 `batch`，必要时再将 `imgsz` 从 `640` 改为 `512` 或 `320`。

### 摄像头打不开

查看设备：

```bash
ls -l /dev/video*
```

如果存在 `/dev/video1`，尝试：

```bash
/home/zros/miniconda3/envs/rl_learning/bin/python capture_images.py --camera 1
```
